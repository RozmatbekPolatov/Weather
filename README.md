# 🌦️ Weather App

A simple and responsive weather application that lets users check real-time weather information for any city.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Current temperature
- ☁️ Weather condition

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Weather API
